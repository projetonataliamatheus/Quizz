# Quiz MR Agência de Marketing

Página única, responsiva e sem dependências para captação de clientes por meio de um quiz de três perguntas.

## Visualização local

Sirva a pasta `dist` com qualquer servidor estático. Exemplo:

```bash
npx serve dist
```

## Publicação na Vercel

Importe a pasta do projeto na Vercel. O arquivo `vercel.json` já aponta a saída para `dist`.

## Carrossel de portfólio

As nove artes otimizadas ficam em `dist/assets/portfolio-01.jpg` até `portfolio-09.jpg`. O carrossel troca automaticamente a imagem a cada 5 segundos.
